# VibeCoded-App-Potluck
Explanation of Prompt:

Before Claude starting to read the prompt and build the website solution I give him the role to be a creative web solution developer, so he has clear who he is in this work. By giving him the role, Claude focuses more on a specific branch, knowledge and practices, in this case as a website solution developer, which reads the problem, analyzes it and it creates a solution.


For this assignment I didn’t just asked Claude to make a website but I first read the problem, I understood what the problem was and then build a solution myself that will work. After having in mind my solution I gave it to Claude to polish it more and make the website. That’s why in the prompt it includes the different users in the website and their functions.


What I have learned throughout this assignment:

I have learned that AI can generate great solutions to everyday problems, and it is a fact, but I learned also to think for a solution for the problem, train my mind and focusing on the

solution. Also, I learned how to structure a good prompt to AI Agents by making them for a task act as a specific role.
